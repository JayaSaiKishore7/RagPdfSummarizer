# 🤖 RAG-Powered PDF Question Answering App

A Flask web app that lets you **upload a PDF** and **ask questions** about it. Answers are generated by
**Gemini 2.0 Flash** from the passages of your document that are most relevant to the question
(Retrieval-Augmented Generation), not from the model's general knowledge.

---

## 🚀 Features

- 📄 Upload a PDF (PDF files only, up to 16 MB)
- 🧠 Ask natural-language questions about its content
- 🔎 Semantic retrieval: the PDF is chunked, embedded and stored in **ChromaDB**
- 💬 Answers from **Gemini 2.0 Flash**, grounded in the retrieved passages and formatted as HTML
- 👥 Each browser session gets its own upload folder and vector store
- 📱 Two-panel web UI: upload on the left, questions and answers on the right

---

## 🧰 Tech Stack

| Area | Tools |
|---|---|
| Web app | Flask |
| PDF parsing | pypdf |
| Chunking | LangChain `RecursiveCharacterTextSplitter` |
| Embeddings | `all-MiniLM-L6-v2` (sentence-transformers, through LangChain) |
| Vector store | ChromaDB |
| LLM | Google Gemini 2.0 Flash (`google-generativeai`) |
| Configuration | `python-dotenv` |

---

## How It Works

1. **Upload:** the PDF is saved to `uploads/<session id>/` and its text is extracted with pypdf.
2. **Chunking:** the text is split into 1,000-character chunks with 200 characters of overlap.
3. **Embedding & storage:** chunks are embedded with `all-MiniLM-L6-v2` and stored in a ChromaDB collection
   under `vector_stores/<session id>/`. Duplicate chunks are detected with an MD5 hash and not embedded twice.
4. **Retrieval:** the question is embedded and the 3 most similar chunks are retrieved.
5. **Generation:** the chunks and the question are sent to Gemini 2.0 Flash, which answers from that context.

## Installation

1. Clone this repository and go to the app folder:
```bash
git clone https://github.com/JayaSaiKishore7/RagPdfSummarizer
cd RagPdfSummarizer/rag-pdf-summarizer
```

2. Create a virtual environment and activate it:
```bash
python -m venv venv
# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Create a `.env` file in `rag-pdf-summarizer/`:
```bash
GOOGLE_API_KEY=your-gemini-api-key        # required
FLASK_SECRET_KEY=any-long-random-string   # optional, signs the session cookie
```

## Usage

1. Start the application:
```bash
python app.py
```

2. Open http://localhost:10000 in your browser
3. Upload a PDF in the left panel
4. Ask a question in the box at the bottom of the right panel

## Limitations

- **One document per session:** a session keeps the vector store of the first PDF it uploads. Uploading a
  second PDF in the same session does not replace it, so questions are still answered from the first one.
  Start a new browser session to work with another document.
- Text is extracted with pypdf only, so scanned PDFs (images without a text layer) yield no content.
- Vector stores are kept in memory and on disk per session and are not cleaned up automatically.
